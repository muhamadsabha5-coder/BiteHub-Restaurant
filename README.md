# BiteHub — Restaurant Ordering System
Individual academic frontend project for CSC1426 Advanced Web Programming.

## Features
- Responsive Home, About, Menu, Order, and Contact pages.
- Dynamic dish detail routes (`/menu/:id`).
- Search and category filtering.
- Add-to-cart, quantity tracking, and total calculation.
- Demo checkout and contact forms.

## Technologies
React, Vite, React Router, CSS3, Lucide-ready icon-friendly UI.

## Run locally
1. Install Node.js LTS: https://nodejs.org/
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite (normally http://localhost:5173).

## Production build
Run `npm run build`.

## Academic scope
This is a frontend prototype. Cart state is kept in the browser; no backend, real payment, or restaurant dispatch is connected.
